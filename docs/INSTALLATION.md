# Installation

## Portable Windows release

1. Open the repository's **Releases** page.
2. Download `PS5-PFS-Packager-v2.13.0-Windows-x64.zip`.
3. Compare the ZIP's SHA-256 with `SHA256SUMS.txt`.
4. Extract the complete ZIP.
5. Run `PS5-PFS-Packager.exe`.
6. Accept the administrator prompt.

Do not run the executable while it is still inside the ZIP archive.

## Recommended folders

Use short, writable paths where possible:

```text
D:\PS5-PFS-Packager
F:\PS5-Games
F:\PS5-Output
F:\PS5-Temp
```

For large images, use an NTFS-formatted SSD or NVMe temp drive.

## SmartScreen

The current community build is not code-signed. Windows may show **Windows protected your PC**.

To continue after verifying the checksum:

1. Click **More info**.
2. Confirm the publisher is shown as unknown.
3. Click **Run anyway**.

Never bypass warnings for files downloaded from unofficial mirrors.
