# PS5 PFS Packager / FFPFSC - exFAT Converter | 15 Languages

Windows GUI for converting PS5 game folders and exFAT images to FFPFSC, with writable image editing, batch processing, compression profiles and 15-language support.

> **Status:** Repository bootstrap is in progress. The full v2.13.0 project package has been prepared locally and will be uploaded as source files / release assets.

## Highlights

- PS5 game folder → exFAT-wrapped `.ffpfsc`
- `.exfat` image → compressed `.ffpfsc`
- Writable exFAT image editing through Windows native VHD mounting
- FFPFSC open / edit / save workflow
- MkPFS `1.1.0`
- Platform selector: `PS5` / `PS4`
- Compression profiles: Fast, Balanced, Maximum, Low RAM
- Block-size selector: `auto`, `auto-fit`, `16384`, `32768`, `65536`
- Automatic low-memory retry
- Pre-flight disk-space and filesystem checks
- 15 interface languages

## Requirements

- Windows 10 / Windows 11 x64
- Administrator rights
- NTFS temp folder recommended
- Windows 7 / 8 / 8.1 are not supported
