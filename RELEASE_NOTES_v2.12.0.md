# PS5 PFS Packager v2.13.0

## Highlights

- Convert PS5 game folders to exFAT-wrapped FFPFSC
- Convert raw exFAT images to compressed FFPFSC
- Open and edit exFAT directly as writable U:
- Open FFPFSC through a temporary exFAT and save changes over the original image
- Single and multi-game conversion
- 15-language interface
- Compression profiles and block-size controls
- Automatic low-memory retry
- Pre-flight disk-space and filesystem checks
- Windows native VHD mounting; no OSFMount or ImDisk required

## Download

Use:

```text
PS5-PFS-Packager-v2.13.0-Windows-x64.zip
```

Verify the package with `SHA256SUMS.txt`.

## Important

- Windows 10/11 x64
- Administrator rights required
- Back up exFAT and FFPFSC images before editing
- No games, keys, firmware or proprietary fakelib files are included
- The executable is not digitally signed
